Visualisations

Three signals hiding in the photographs

Before the network runs, each photo is reduced to colour and texture measurements. These are not the pixels themselves. They are the clues a scout can see: how green the leaf is, how much red the rust adds, and how broken-up the surface looks.

Green share against rust index

Each point is one training leaf.

Retraining

Teach the saved model with new leaves

Uploads are stored on disk and recorded in SQLite. Retraining does not start from scratch: it loads the custom model already trained for this project and fine-tunes it. An automatic trigger starts that job once enough new leaves are waiting.
